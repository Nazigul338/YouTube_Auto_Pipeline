About this project

YouTube Auto Pipeline is a personal video-production project. It is intended to help its owner organize files and automate parts of a video workflow.

Google account access is requested only when needed for a feature that the user chooses to use.

Privacy Policy

Last updated: November 16, 2026

This project is operated for personal use. It does not sell personal information or use Google user data for advertising.

Google account data

If you choose to authorize Google services, the project may access only the Google data and permissions shown on Google's consent screen, for the purpose of carrying out the video-workflow actions you request.

Storage and sharing

Google data and authorization tokens should be stored securely and should not be shared publicly. The project owner should limit access to authorized devices and services. No Google user data is intentionally sold or shared with advertisers.

Data deletion and revoking access

You can revoke this project's Google account access at any time from your Google Account security settings. You can also delete project files from the storage location where you saved them.

Contact

For privacy questions, contact the project owner through the GitHub repository where this project is published.
