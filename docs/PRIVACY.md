# Privacy Policy — Video Auto Pipeline

Video Auto Pipeline is a personal, non-commercial automation tool used by its
owner to produce their own videos.

**What the app accesses.** With the owner's explicit consent (OAuth), the app
reads music files from one Google Drive folder (`YouTube_Auto/Music`) and uploads
finished video files to another (`YouTube_Auto/Videos`) in the owner's own Google
account.

**What the app does not do.** It does not collect, sell, share or publish any
personal data. It does not access any other person's account. It does not
transfer Google user data to third parties.

**Storage.** Access credentials are stored only as encrypted GitHub Actions
secrets of the owner's repository. No user data is stored on any other server.

**Revoking access.** The owner can revoke access at any time at
https://myaccount.google.com/permissions.

**Contact.** Open an issue at
https://github.com/Nazigul338/YouTube_Auto_Pipeline/issues.
