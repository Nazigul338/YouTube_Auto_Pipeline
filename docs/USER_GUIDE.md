# 📱 Колдонуу нускамасы — видео жасоо (GitHub Actions)

Colab керек эмес. Бардык иш GitHub'дын серверинде жасалат, телефон өчүк болсо да иштей берет.

## 1. Жаңы видео жасоо (30 секунд сиздин иш)

1. Телефондон браузерде ачыңыз:
   **github.com/Nazigul338/YouTube_Auto_Pipeline/actions**
   (керек болсо браузерде ⋮ → **Desktop site**)
2. Сол жактан **🎬 Видео жасоо** тандаңыз.
3. Оң жактагы **Run workflow** баскычын басыңыз.
4. **topic** талаасына теманы жазыңыз (орусча же кыргызча — сценарий баары бир орусча жазылат).
   Калган талааларды тийбей коюңуз.
5. Жашыл **Run workflow** баскычын басыңыз.

Болжолдуу убакыт: **40–70 мүнөт**. Күтүүнүн кереги жок — бүткөндө GitHub email жиберет.

## 3. YouTube'га жүктөөдөн мурун (сиз гана жасайсыз)

1. Видеону **толук көрүп чыгыңыз**.
2. `Projects/Video_00N/report.txt` — QA отчетун окуңуз.
3. `youtube_description.txt` ичиндеги **Music: …** сабын сүрөттөмөгө сөзсүз кошуңуз
   (YouTube Audio Library'нин атрибуция шарты).
4. `Subtitles/Video_00N.srt` файлын YouTube Studio → Subtitles бөлүмүнө жүктөсөңүз болот.
5. **AI белгилөө**: `report.txt`'тин аягындагы сунушту окуңуз. Акыркы чечим — сиздики.

Система видеону YouTube'га **өзү жарыялабайт** — бул атайын.

## 4. Ката чыкса

GitHub бетиндеги иштин **Summary** бөлүмүндө кайсы этапта, эмне себептен токтогону
жазылат жана ID көрсөтүлөт (мис. `Video_004`).

**Улантуу**: Run workflow → **video_id** талаасына `Video_004` жазыңыз (topic бош) → Run.
Бүткөн этаптар кайра жасалбайт, система токтогон жеринен улантат.

**Бир этапты кайра жасоо**: video_id + **rerun_from** (мис. `s3_voice` — үндү кайра жаратуу).

| Ката | Себеби жана чечими |
|---|---|
| `refresh token эскирген` | Google колдонмосу «Testing» режиминде — токен 7 күндө өчөт. `docs/GITHUB_ACTIONS_SETUP.md` B5 кадамы менен жаңы токен алып, `GDRIVE_REFRESH_TOKEN`'ди алмаштырыңыз |
| `квота/лимит бүттү` | Gemini'нин акысыз күнүмдүк лимити бүттү — эртең ошол эле video_id менен улантыңыз |
| `503 high demand` | Gemini убактылуу бош эмес — система өзү кайра аракет кылат жана запас моделге өтөт |
| `QA өткөн жок` | `report.txt`'те ❌ белгиленген пункттарды караңыз |
