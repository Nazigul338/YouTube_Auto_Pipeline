# 📱 Колдонуу нускамасы — видео жасоо (GitHub Actions)

Colab керек эмес. Бардык иш GitHub'дын серверинде жасалат, телефон өчүк болсо да иштей берет.

## 1. Жаңы видео жасоо (30 секунд сиздин иш)

1. Телефондон браузерде ачыңыз:
   **github.com/Nazigul338/YouTube_Auto_Pipeline/actions**
   (керек болсо браузерде ⋮ → **Desktop site**)
2. Сол жактан **🎬 Видео жасоо** тандаңыз.
3. Оң жактагы **Run workflow** баскычын басыңыз.
4. **topic** талаасына теманы жазыңыз (орусча же кыргызча — сценарий баары бир орусча жазылат).
   Калган талааларды тийбей коюңуз.
5. Жашыл **Run workflow** баскычын басыңыз.

Болжолдуу убакыт: **40–70 мүнөт**. Күтүүнүн кереги жок — бүткөндө GitHub email жиберет.

## 3. YouTube'га жүктөөдөн мурун (сиз гана жасайсыз)

1. Видеону **толук көрүп чыгыңыз**.
2. `Projects/Video_00N/report.txt` — QA отчетун окуңуз.
3. `youtube_description.txt` ичиндеги **Music: …** сабын сүрөттөмөгө сөзсүз кошуңуз
   (YouTube Audio Library'нин атрибуция шарты).
4. `Subtitles/Video_00N.srt` файлын YouTube Studio → Subtitles бөлүмүнө жүктөсөңүз болот.
5. **AI белгилөө**: `report.txt`'тин аягындагы сунушту окуңуз. Акыркы чечим — сиздики.

Система видеону YouTube'га **өзү жарыялабайт** — бул атайын.

## 4. Токтоп калса (көбүнчө өзү улантылат)

**🔁 «Токтоп калган видеону улантуу»** workflow'у күн сайын өзү иштейт
(Бишкек убактысы менен ~14:30 жана ~21:30). Сиз эч нерсе баспайсыз.

| Токтоо себеби | Эмне болот |
|---|---|
| Gemini'нин **күнүмдүк акысыз квотасы бүттү** | Эртеси квота жаңыланганда өзү улантат |
| **Убактылуу ката** (503, тармак) | Кийинки аракетте өзү улантат |
| Иш **үзүлдү** (убакыт бүттү, жокко чыгарылды) | Өзү улантат |
| **Чыныгы ката** (мис. QA өткөн жок, ачкыч жок) | Автоматтык **уланбайт**. Кызыл ❌ + email келет, себеби Summary'де |

Чектер: бир видео максимум 6 жолу автоматтык уланат; 10 күндөн эски видео уланбайт.

Улантуу иштеп жатканда экранда эч нерсе көрүнбөйт — бүткөндө Drive'да `Final_Videos/`
ичинде видео пайда болот (GitHub email да жиберет).

### Колго улантуу (керек болсо)
Actions → **🎬 Видео жасоо** → Run workflow → **video_id** = `Video_004` (topic бош).
Бир этапты кайра жасоо: video_id + **rerun_from** (мис. `s3_voice`).

| Ката | Себеби жана чечими |
|---|---|
| `refresh token эскирген` | Google колдонмосу «Testing» режиминде — токен 7 күндө өчөт. `docs/GITHUB_ACTIONS_SETUP.md` B5 менен жаңы токен алып, `GDRIVE_REFRESH_TOKEN`'ди алмаштырыңыз |
| `КҮНҮМДҮК квота бүттү` | Күтүңүз — 🔁 workflow эртеси өзү улантат |
| `503 high demand` | Gemini убактылуу бош эмес — система өзү кайра аракет кылат |
| `QA өткөн жок` | `Projects/Video_00N/report.txt`'те ❌ пункттарды караңыз |

> GitHub эскертүүсү: ачык репозиторийде 60 күн эч кандай иш болбосо, расписание
> workflow'дору өзү өчүп калат. Андай болсо Actions → 🔁 → **Enable workflow** басыңыз.
