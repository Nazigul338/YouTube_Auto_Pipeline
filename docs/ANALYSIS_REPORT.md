## 2. Табылган каталар жана көйгөйлөр

### Код каталары
1. **Клетка 157** — синтаксис катасы: `"-c": "copy"` жана `"-c:a": "aac"` (тизмеде `:` колдонулган, `,` болушу керек). Бул клетка иштебейт.
2. **Клетка 165** — бир нече клетка бири-бирине жабышып калган (коддун ортосуна `from google.colab import files` кошулуп кеткен). Иштебейт.
3. Drive эки жолго монтаждалган: `/content/drive` жана `/content/gdrive` (клетка 62) — жолдор чаташат.
4. Ачкыч бир жерде Secrets'тен, башка жерде `getpass` менен суралат (клетка 137, 155).

### Архитектуралык көйгөйлөр
5. **239 клетка кол менен ирети менен басылат** — бир баскыч жок.
6. **Тема коддун ичинде катуу жазылган** (`TOPIC = "..."`).
7. **Мурунку файлдар жоголот**: клетка 12 ар дайым `video_001.txt` деп жазат — жаңы видео эскисин үстүнөн басып кетет. Бардык жолдор `video_001` деп бекитилген.
8. Ар бир видео үчүн өзүнчө папка жок.
9. Этаптын абалы сакталбайт — Colab өчүп калса, баарын башынан баштоо керек.
10. Ката чыкканда кайсы этапта экени көрсөтүлбөйт (көп клеткада `check=True` + `DEVNULL`, ката тексти жашырылат).

### Сапат көйгөйлөрү
11. **Үн Orus, сиз каалаган Algenib эмес.**
12. `atempo=0.85` — үндү жасалма жайлатуу. Бул тембрди бузуп, «робот» эффектин берет. Туурасы — ылдамдыкты TTS көрсөтмөсү (style prompt) аркылуу башкаруу.
13. Бөлүктөр ар кайсы генерацияда түзүлгөндүктөн, үн бөлүктөр ортосунда өзгөрүп кетет (сиз аны «same6» версиялары менен кол менен оңдогонсуз). Ар бир бөлүккө бирдей стиль + текшерүү керек.
14. **Клиптер текстке туура келбейт** — издөө сөздөрү ("man procrastinating", "sunrise mountain"...) кол менен жазылган. 8 мүнөт × 3.5 сек ≈ **130–140 кадр** керек, азыр 15 гана.
15. 140 клипти бир `filter_complex` ичинде 2560×1440 zoompan менен монтаждоо Colab'да эс тутумду бүтүрүп, сааттап иштейт. Ар бир сахнаны өзүнчө рендерлеп, анан бириктирүү керек.
16. Музыка жок, ducking (сүйлөгөндө музыканы басаңдатуу) жок, үн деңгээли (loudness) нормалдаштырылган эмес.

### Монетизация жана лицензиялар
17. Pixabay клиптеринин ID/автор/шилтемеси эч жерде жазылбайт — кийин лицензияны далилдөө мүмкүн эмес.
18. `music.mp3` кайдан алынганы белгисиз — лицензиясы текшерилиши керек. Белгисиз музыка Content ID доосуна алып келиши мүмкүн.
19. YouTube «inauthentic/reused content» саясаты: бир шаблон менен массалык видео — монетизациядан баш тартууга себеп. Ар бир видеодо сапат текшерүүсү жана акыркы адамдык көрүү (preview) этабы болушу керек.

## 3. Сунушталган архитектура

Колаб блокноту **кичинекей** болот (3–4 клетка), ал эми бардык логика GitHub'дагы модулдарда болот. Блокнот репозиторийди клондоп, бир функцияны чакырат.

```
YouTube_Auto_Pipeline/
├── notebooks/
│   └── RUN_PIPELINE.ipynb        ← Телефондон: тема жаз → ▶ бас
├── pipeline/
│   ├── config.py                 ← моделдер, үн, резолюция, жолдор
│   ├── state.py                  ← state.json: ар бир этаптын абалы
│   ├── runner.py                 ← этаптарды ирети менен, retry/resume
│   ├── stages/
│   │   ├── s1_script.py          ← Gemini: жаратуу → редакция → текшерүү, 1100–1200 сөз
│   │   ├── s2_scenes.py          ← сценарийди сахналарга бөлүү + ар бирине визуалдык ачкыч сөздөр
│   │   ├── s3_voice.py           ← Gemini TTS, Algenib, бөлүктөп + бириктирүү + loudnorm
│   │   ├── s4_subtitles.py       ← Whisper: сөз деңгээлиндеги убакыт → SRT/ASS
│   │   ├── s5_visuals.py         ← Pixabay (+Pexels), сахнанын убактысына жараша 3–4 сек кадрлар
│   │   ├── s6_music.py           ← лицензиясы бар музыка, ducking
│   │   ├── s7_render.py          ← FFmpeg: сахна-сахна рендер → concat → субтитр → аудио
│   │   └── s8_qa.py              ← узактык, үн деңгээли, кара кадр, лицензия отчету
│   └── niches/
│       ├── motivation.yaml       ← промпттор, стиль, үн, музыка маанайы
│       └── (cooking.yaml, history.yaml ... кийин)
├── legacy/                       ← эски блокноттун көчүрмөсү
└── docs/
```

### Drive'дагы ар бир видеонун папкасы

```
MyDrive/YouTube_Auto/Videos/2026-11-15_pochemu-ty-otkladyvaesh/
├── state.json          ← кайсы этап бүттү, кайсы катага учурады
├── script.txt          ← акыркы сценарий (+ draft_1, draft_2)
├── scenes.json         ← сахналар, тексттер, издөө сөздөрү, убакыт
├── audio/voice.wav
├── subs/subs.srt, subs.ass
├── clips/              ← жүктөлгөн клиптер
├── licenses.json       ← ар бир клип/музыка: булак, ID, автор, URL
├── metadata.json       ← аталыш/сүрөттөмө/теги сунуштары
└── final.mp4           ← даяр видео
```

Эрежелер:
- Бар болгон файл **эч качан үстүнөн жазылбайт** (жаңы версия `_v2` деп сакталат).
- Ар бир этап бүткөндө `state.json`'го жазылат → Colab өчсө, `▶` кайра басканда калган жеринен улантат.
- Ката чыкса: `❌ 3-ЭТАП (Үн): <себеби>` жана ошол этапты гана кайра иштетүү баскычы.
- Ачкычтар гана Colab Secrets'те (`GOOGLE_API_KEY`, `PIXABAY_API_KEY`, кааласаңыз `PEXELS_API_KEY`).

## 5. Иштөө планы (ар бир кадам сиздин уруксатыңыз менен)

1. **Каркас**: `config`, `state`, `runner`, бир баскычтуу блокнот. Тест: бош папка түзүлүп, state.json жазылат.
2. **1-этап — Сценарий** (эски промпттор негизинде, сөз санын автоматтык текшерүү).
3. **2-этап — Сахналар** (Gemini ар бир сахнага англисче издөө сөздөрүн берет).
4. **3-этап — Үн** (Algenib, жасалма жайлатуусуз, бөлүктөрдү салыштыруу, loudnorm −14 LUFS).
5. **4-этап — Субтитрлер** (Whisper + сценарий тексти менен оңдоо).
6. **5-этап — Визуалдар** (кадр 3–4 сек, кайталанбаган клиптер, licenses.json).
7. **6-этап — Музыка** (лицензиясы так булактан, ducking).
8. **7-этап — Монтаж** — алгач 60 сек тест, андан кийин гана толук 8 мүнөт.
9. **8-этап — QA отчету** + metadata (аталыш, сүрөттөмө).
10. Кийин: ниша профилдери (кулинария, тарых, бизнес...), vidIQ анализи.

**vidIQ жөнүндө**: vidIQ'тун Colab үчүн ачык API'си жок. Тема тандоону мен (Claude) vidIQ туташтыргычы аркылуу жасап, даяр темалардын тизмесин берсем болот — андан кийин Colab'га теманы гана киргизесиз.
