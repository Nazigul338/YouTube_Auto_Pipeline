# 🔊 Sound Effects Library (СЫНАК режими)

Үн эффекттери видеонун сценасына жараша автоматтык тандалат (`pipeline/sfx.py`).
Иштетүү: Actions → **🎞 Cinematic сынак** → `sound_effects` ✓ (YouTube_Auto_TEST гана; production өзгөрбөйт).

## Аудио кайда салынат
**Google Drive:** `YouTube_Auto/Sound_Effects/<категория>/` (папкаларды система өзү түзөт).
Бул репозиторий ачык — аудионун өзүн бул жерге коммит кылбаңыз (`.gitignore` бөгөйт).

| Категория | Эмне үчүн |
|---|---|
| `cinematic` | riser/swell — чечүүчү, үмүт берген учур |
| `atmosphere` | өтө акырын фон — тынч/ойлуу сахна |
| `nature` | токой, шамал, суу, жамгыр — табият көрүнгөн сахна |
| `transitions` | whoosh — сахна алмашуусу |
| `impact` | сокку/boom — драмалуу учур (≤3 видеого) |
| `emotional` | жумшак пианино/струна — сезимдүү сахна |

## Ар бир аудио үчүн metadata (милдеттүү)
`whoosh_soft_01.wav` жанына `whoosh_soft_01.metadata.json` (үлгү: `metadata.example.json`).

Милдеттүү талаалар: `title, file, category, source, source_url, license, commercial_use,
verified_by, verified_at`. Кошумча: `author, license_url, attribution_required, tags, mood, sha256`.

## Лицензия капкасы — текшерилбесе видеого КОШУЛБАЙТ
- `commercial_use: true` (лицензияны СИЗ окуп тастыктайсыз);
- лицензия уруксат берилген тизмеде: **CC0**, **Pixabay Content License**, **Mixkit Free License**;
- категория папкага, `file` файлдын атына дал келет; `sha256` жазылса — файлга дал келет.

Четке кагылган аудио себеби менен логго жазылат («🔇 SFX четке кагылды: … — …»).

## Булактар
- **Оригиналдуу эффекттер:** `python -m pipeline.sfx_synth <папка>` — 15 эффект нөлдөн синтезделет (whoosh, boom,
  braam, chime/piano/pad, drone, шамал, жамгыр, толкун); автору ушул долбоор, лицензия CC0 1.0, metadata өзү түзүлөт.
- Аудиону сайттан **өзүңүз** жүктөп, Drive'га саласыз. Система эч бир сайттан (ZvukiPro ж.б.)
  автоматтык жүктөбөйт жана scraping жасабайт.
- ZvukiPro'дон алсаңыз: сайттын лицензиясын окуп, коммерциялык колдонууга уруксат болсо гана,
  лицензиянын так атын жазыңыз. Ал уруксат берилген тизмеде болбосо — тизмеге кошууну өзүңүз чечесиз.

## Деңгээл
Деңгээл диктордун өлчөнгөн үнүнө жараша коюлат: «сокку» эффекттери диктордун паузасына, 12–14 LU
акырын (пик ≤ −6 dBFS); фондор 22–24 LU акырын жана диктор сүйлөгөндө музыка менен бирге басаңдайт. QA: диктор эффекттерден ≥10 LU катуу.
